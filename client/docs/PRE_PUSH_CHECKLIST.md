# Pre-Push Checklist

Trước khi push code lên repository, hãy chạy các lệnh dưới đây để đảm bảo code được format, lint và build thành công.

## Các lệnh cần chạy

```bash
npm format
npm format:check
npm lint
npm build
```

## Tại sao cần làm việc này?

Các bước trên giúp mọi người sử dụng cùng một format và hạn chế các lỗi về lint hoặc build khi làm việc chung trên project.
Mục tiêu là giữ code trong project có format và style thống nhất giữa tất cả thành viên.
